# farminvestro-blog-poster

Standalone Vercel service. Auto-posts SEO articles to Blogger
(`farminvestro.blogspot.com`) 3x/week (Mon/Wed/Fri UTC), rotating 8
non-Thai languages, each with one backlink to `eafarmforex.com`. Content
is generated by Gemini. Separate from the main app.

## How it works

- `vercel.json` cron hits `/api/post` daily; the handler self-gates to
  Mon/Wed/Fri (UTC) and skips other days.
- `lib/rotation.ts` picks `{lang, topic}` deterministically from the date
  (no DB). Languages: `en, lo, vi, id, tl, tr, ar, zh`.
- `lib/gemini.ts` generates a unique `{title, html}` and **rejects** output
  that lacks the correct backlink (`https://www.eafarmforex.com/{lang}`).
- `lib/blogger.ts` exchanges the refresh token for an access token,
  checks there is no `auto`-labelled post today (dup guard), then inserts
  the post via Blogger API v3.

## Setup

1. **Gemini API key** (free): https://aistudio.google.com → Get API key
2. **Blogger API + OAuth** (Google Cloud):
   - Create/select a project → enable **Blogger API v3**
   - Credentials → create **OAuth client ID** → type **Desktop app**
   - Note the client id + secret
3. **Refresh token** (one-time, local; loopback flow, oob is deprecated):
   ```bash
   node scripts/oauth.mjs ./client_secret_XXX.json
   ```
   (or set `GOOGLE_OAUTH_CLIENT_ID`/`GOOGLE_OAUTH_CLIENT_SECRET` and omit the path).
   Open the printed URL, approve (Advanced → Go to… if it warns unverified).
   It captures the redirect on `localhost` and prints `BLOGGER_REFRESH_TOKEN`.
4. **Deploy** (new Vercel account):
   - Push this repo to GitHub, import into Vercel
   - Set env vars (see `.env.example`): `GEMINI_API_KEY`, `BLOGGER_BLOG_ID`,
     `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`,
     `BLOGGER_REFRESH_TOKEN`, `CRON_SECRET` (random)
   - Deploy. The cron in `vercel.json` registers automatically.

## Test manually

```bash
curl "https://<your-deployment>/api/post?secret=<CRON_SECRET>"
```
On a non-post day it returns `{"skipped":true,...}`. Force a real post by
testing on a Mon/Wed/Fri (UTC) or temporarily relaxing the slot check.

## Dev

```bash
npm install

```

## Notes

- 3 posts/week + unique content + single contextual backlink keeps this
  below Google's obvious link-spam thresholds. Do not raise frequency or
  add more backlinks per post.
- No secrets are committed; `.gitignore` blocks `.env*` and token files.
